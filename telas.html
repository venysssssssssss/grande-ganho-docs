Matriz das 31 telas ​

Este inventário mapeia o desenho do produto às capacidades da API. Nenhuma tela frontend está implementada nesta entrega. "API confirmada" significa rota presente no OpenAPI gerado desta entrega; "API parcial confirmada" indica somente os recursos listados, com o restante planejado. Isso não comprova implantação cloud ou integração de uma interface. "Planejada" significa contrato de produto futuro, sem endpoint fictício. A lista foi aprovada como o inventário do produto; não é uma enumeração inferida da reunião.

Integração do frontend ​

O cliente deve criar primeiro autenticação, contexto, carteira, 360, ações e plano com o contrato gerado, usando os métodos e schemas das rotas confirmadas. Os filtros de uma lista são definidos por schemas; o frontend não envia SQL, nomes arbitrários de colunas ou tenant de confiança.

Todo campo exibido deve preservar seu significado. Um pilar sem valor mostra "Sem avaliação"; um valor antigo mostra a data observada. Se a projeção exclui dados, o cliente não mostra um selo que revele a existência de um registro protegido. O direito à existência de uma informação é parte da política de acesso.

Nas telas planejadas, a interface pode informar indisponibilidade da funcionalidade; não apresentar botões que simulam envio, compra, recomendação ou sincronização. Mock de desenvolvimento deve ser marcado e usar exclusivamente dados sintéticos.
